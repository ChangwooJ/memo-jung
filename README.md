# memo jung

정창우의 커피 테마 개인 블로그 첫 버전. React + Vite + Three.js로 만든 프런트엔드 프로토타입입니다.

## 실행

Node.js 22.12 이상 또는 24를 사용합니다.

```powershell
cd C:\SSAFY\changwooj\memo-jung
npm.cmd install
npm.cmd run dev
```

개발 주소: http://127.0.0.1:5173

Windows PowerShell 실행 정책에 영향받지 않도록 `npm.cmd`를 표기했습니다. macOS/Linux에서는 `npm`을 사용합니다.

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run test:e2e
```

브라우저 테스트는 개발 서버를 실행한 상태에서 사용하며 설치된 Google Chrome을 사용합니다. 단계별 검증 화면은 `.artifacts/`에 저장합니다.

## 첫 버전 범위

- 투명한 글 목록, 카테고리, 검색, 정렬, 더 보기
- 해시 URL을 이용한 글 상세 페이지 및 뒤로 가기
- 소개 대화상자, 키보드 검색(`/`), Escape 닫기, 본문 바로가기
- 데스크톱/태블릿/모바일 대응
- WebGL을 사용할 수 없을 때 CSS 유리잔으로 대체
- 모션 감소 설정을 사용하면 인트로와 흐름을 생략하고 정적인 잔 표시

현재 글 6개는 미리보기를 위한 샘플입니다. 로그인, 글 작성·수정, 댓글, 업로드, 데이터베이스 및 티스토리 연동은 아직 포함하지 않았습니다.

## 커피 연출

1. 윤기 있는 작은 커피 방울들이 모여 `Hi, I'm Changwoo Jung!`의 형태를 만듭니다. 단단한 글자 메시 없이 방울만으로 구성합니다.
2. 글자 가장자리의 방울부터 불규칙하게 풀리며 중력과 약간의 좌우 흔들림을 따라 바닥으로 떨어집니다.
3. 커피 웅덩이가 다시 모여 뚜껑이 열린 포트로 들어갑니다.
4. 포트가 첫 번째 글의 유리잔에 한 번 커피를 붓습니다.
5. 첫 잔이 가득 차면 다음 잔으로 넘쳐 흐릅니다. 아래 잔도 차례로 채워집니다.
6. 포트는 원래 자리로 돌아와 멈추고, 잔 사이 흐름만 계속됩니다.

인트로는 페이지 로드 후 한 번 실행합니다. 카테고리 변경이나 글 상세에서 복귀할 때는 되풀이하지 않습니다. 새로고침 또는 다시 보기 버튼으로 재생할 수 있습니다. 일시정지와 모션 감소 상태에서는 움직이지 않는 장면을 매 프레임 다시 그리지 않습니다.

실제 유체 역학 솔버 대신 곡면 메시, 표면 파동, 광택 재질, 물방울, 단계별 타이밍으로 액체를 표현했습니다. 페이지 전체에 덮는 투명 WebGL 캔버스가 실제 글 목록 위치를 측정하므로 스크롤·필터·화면 크기 변경에도 잔과 글 번호가 연결됩니다. DOM 글 내용은 캔버스와 분리되어 선택·검색·키보드 탐색이 가능합니다.

## 변경할 곳

| 파일                            | 역할                             |
| ------------------------------- | -------------------------------- |
| `src/App.jsx`                   | 홈, 필터, 글 상세, 소개          |
| `src/data.js`                   | 샘플 글, 카테고리, 검색          |
| `src/styles.css`                | 레이아웃, 색상, 반응형 스타일    |
| `src/animation/timeline.js`     | 인트로 단계, 잔 채우는 순서      |
| `src/animation/engine.js`       | 3D 글자, 포트, 유리잔, 액체 표현 |
| `src/animation/CoffeeScene.jsx` | React와 WebGL 생명주기 연결      |

Three.js는 동적으로 불러오며 폰트는 로컬 패키지에서 제공합니다. 프로덕션 빌드에서 Three.js 청크 크기 안내가 나올 수 있습니다.
